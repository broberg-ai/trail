trail

widget · local demo

This page embeds <trail-chat> the same way any customer site would. The widget bundle is served from this dev server at /widget.js, and the chat-proxy endpoints sit at /api/chat-proxy/{chat,feedback}.

Mode: checking… Set TRAIL_API_KEY + TRAIL_KB env to switch to real mode.

How this works

<script type="module" src="/widget.js"></script>
<trail-chat api="/api/chat-proxy" theme="auto"></trail-chat>

The api attribute points at your own server's proxy route — never directly at engine.trailmem.com. The proxy holds the bearer key.

Try it

Type a question, hit Enter (Shift+Enter for newline). Use 👍/👎/🚩 under each answer to send feedback into the curator queue (stub mode: feedback is logged to the demo server's stdout; real mode: lands in app.trailmem.com's queue).
