# F201.16 — Capture noise-suppression (voice-processing)

> Sub-story of F201 (Trail Ambient). Fixes the Prompt Mode noise dependency
> found 2026-07-04: dictation truncated badly unless macOS Noise Cancellation
> was on.

## Motivation
Prompt Mode uses Apple's on-device STREAMING recognizer (for speed — it injects
into the focused cc-session on stop). On a NOISY mic signal (Noise Cancellation
off) the recognizer produces poor/short output — a 12s dictation came back as one
clipped line; the same speech with NC on captured the full sentence. Log
evidence: NC-off run injected 72 chars, NC-on run 215 chars.

The accumulation logic is correct (a config-change restart preserves prior text
— the NC-on run had the same restart and still captured everything). The problem
is input quality: Apple's recognizer degrades on noisy audio.

WhisperKit batch would be robust to noise but measured ~1.01x realtime warm
(15s dictation -> ~15s wait), so it is NOT viable for Prompt Mode's
inject-quickly UX (measured 2026-07-05: 15s clip 28.2s, 169s clip 183.8s incl.
~13s one-time model load).

## Scope
- Enable macOS **voice-processing IO** on the AVAudioEngine input node
  (`inputNode.setVoiceProcessingEnabled(true)`) in `buildEngineAndTap`. This is
  the system's built-in noise-suppression + echo-cancellation + AGC — the same
  processing "Noise Cancellation" applies. The streaming recognizer (and the
  Extraction recorder) then get CLEAN audio, so capture no longer depends on the
  user toggling NC.
- Best-effort: wrap the enable in try/catch; on an unsupported device/route,
  log and fall back to raw input so capture is never broken.
- Re-enabled on every graph rebuild (config-change path builds a fresh engine).

## Non-goals
- No WhisperKit model change; no second model download.
- No latency added (this is instant, unlike batch).
- AGC tuning (isVoiceProcessingAGCEnabled) left at default for v1.

## Rollout
- App-only (apps/ambient-capture). Rebuild + re-sign + relaunch. No server/deploy.
- Benefits BOTH modes: Prompt Mode (cleaner streaming) and Extraction (cleaner
  recording feeding the batch pass + the kept .wav).

## Acceptance criteria
- AC1: capture enables voice-processing; unsupported route falls back to raw
  input without breaking capture (logged, not thrown).
- AC2: headless gate stays green (no audio-path regression).
- AC3 (field, Christian): a Prompt-Mode dictation with NC OFF injects the FULL
  utterance, not a clipped line.
