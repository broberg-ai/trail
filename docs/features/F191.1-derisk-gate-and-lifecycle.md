## The $0 "gate" — resolved by construction (not a billing spike)

Christian's correction: there is nothing to measure in a billing dashboard. An **interactive cc session runs on the Max subscription** — when it compiles a source and writes Neurons via trail MCP, it uses **no `ANTHROPIC_API_KEY` and spawns no `claude -p`**, so it is $0 *structurally*. The absence of any API key / subprocess in the path IS the proof. The only thing Anthropic API-bills is headless `claude -p` — which this path never uses (and which means F190.6's "claude-cli backend = free" assumption is now FALSE; flagged to ai-sdk re `transport:"subprocess"`).

**Invariant F191 must hold:** the compile is ALWAYS the interactive session's own MCP work — never `claude -p`, never an API key. As long as that holds, it's free. No spike needed.
