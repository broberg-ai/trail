# F191.1 — De-risk gate + `awaiting-local-compile` lifecycle

Parent: [F191](./F191-local-ingest-station.md). Shared architecture lives in the epic doc.

## Why first
The entire epic rests on one unverified claim: that compiling inside an **interactive** cc session is $0 on Max. Anthropic API-bills headless `claude -p`; we must NOT assume the interactive path is free without proof. This story is the gate — if it fails, F191 stops.

## Scope
1. **De-risk spike (P0).** From an interactive cc session, compile one real source via trail MCP `write` against a test cloud KB. Verify $0 (check the Anthropic/Max usage surface + that no metered API charge appears). Separately confirm headless `claude -p` DOES bill (re-run the same via `claude -p` and observe the charge). Record the finding in the plan-doc + a Neuron. Flag to ai-sdk that `transport:"subprocess"` (`claude -p`) is no longer $0.
2. **Lifecycle.** Add an `awaiting-local-compile` state to a source (status value or boolean flag on `documents`). Station uploads set it; the cloud ingest path skips OpenRouter compile for such sources (they wait for the local cc skill). Expose a query (REST + reachable via trail MCP) for pending sources scoped to tenant/KB.

## Non-goals
No Station UI, no skill yet (F191.2/.3). Just the gate + the backend state.

## Dependencies
Trail MCP write from interactive cc (exists); `documents` schema (packages/db); ingest trigger in apps/server/src/services/ingest.ts (skip-compile branch).

## Verify
Scripted probe under apps/server/scripts/ that asserts the awaiting state round-trips + the cloud compile is skipped for flagged sources. The $0 finding is documented, not inferred.
