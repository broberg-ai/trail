# F191.4 — Station live progress + UX

Parent: [F191](./F191-local-ingest-station.md).

## Scope
Wire the Station to the existing `/api/v1/stream` SSE bus (the one fixed 2026-06-03) so compile progress is live: as the cc skill writes Neurons, `candidate_created`/`candidate_resolved` events update the matching source rows from awaiting → compiling → done. Reuse apps/web's EventSource client (apps/admin/src/lib/event-stream.ts) via the shared package where sensible.

## Waiting state
Because compile only happens when a cc session drains the queue (the deliberate Model-B constraint), the Station must make that visible: a clear "waiting for an active ingest session" state when sources are parked awaiting-local-compile but nothing is draining — not a silent stuck queue. Optionally surface a hint to run `/local-ingest`.

## Non-goals
No polling fallback unless SSE proves unreliable; no compile logic here.

## Dependencies
F191.1 (states), F191.2 (skill emits the events), F191.3 (shell). SSE via the admin proxy (fixed).
