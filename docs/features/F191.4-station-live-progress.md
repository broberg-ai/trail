# F191.4 — Station live progress + UX  ✅ shipped (code-complete + build-clean)

Parent: [F191](./F191-local-ingest-station.md).

## What shipped
- **Live progress via `/api/v1/stream`.** Key gotcha solved: `EventSource` cannot send an `Authorization` header, and the Station auths with a Bearer `trail_` key (not a cookie). So the Station consumes the SSE stream via **`fetch` + a `ReadableStream` reader**, parsing SSE frames itself (`api.ts subscribeStream`). `candidate_created` / `candidate_resolved` / `ingest_started` events for the active KB refresh its source list live — no manual reload. (Directly reuses the SSE-through-proxy fix shipped 2026-06-03.)
- **Waiting-for-session UX.** When sources are parked `awaitingLocalCompile`, a banner shows "N kilder venter på en aktiv ingest-session" with the `/local-ingest <kb>` hint — the deliberate Model-B constraint (compile only happens when a cc session drains) made visible, not a silent stuck queue.
- Status badges: Afventer lokal compile / Kompilerer / Færdig / Fejlet.

## Verification
Typecheck + `vite build` clean. **NOT browser-verified** — the SSE-over-fetch + live-refresh loop needs a real browser run against the live stream. Flagged honestly.

## Dependencies
F191.1 (states), F191.2 (skill emits the events), F191.3 (shell). SSE through the admin proxy (fixed 2026-06-03).
