# F191.6 — Multi-tenant Station auth (one key, all my tenants)

**Parent:** [F191 — Local Ingest Station](F191-local-ingest-station.md)
**Status:** building
**Owner:** trail cc session

## Motivation

The Ingest Station (F191.3) auto-logs-in on localhost with a personal
`trail_` key from `.env.local-ingest` (F191 CLI + auto-login). That key is
**bound to ONE tenant** (`control_api_keys.tenant_id`, F188) — currently
`broberg-ai`. But Christian's primary need is to land source material into
**Sanne Andersen's** trail too, and he wants to do it **without physically
logging in** — just keep the auto-login and "give me more privileges."

So: the auto-login key must span **every tenant Christian is a member of**,
and the Station must let him pick which one he's dropping into.

## Prod reality (verified 2026-06-04 against trail-admin `/data/control.db`)

This is far simpler than F188's "Phase 2+ cross-tenant" sketch assumed:

- **One org**: `org-sanne-andersen` (slug is historical; it IS the org).
- **Two tenants, both in that org, both on the same engine** (trail-engine-001):
  `broberg-ai` ("Broberg.ai") + `sanne-andersen` ("Sanne Andersen").
- `cb@webhouse.dk` (`u-cb-webhouse`) is **`owner` on BOTH** via
  `control_memberships`.
- Each tenant has its own per-tenant engine bearer in `tenant_engines.bearer`.

So no new orgs, no new memberships, no engine routing changes are needed —
only a key that resolves to a chosen membership tenant per request.

## Scope

**In:**
1. **`scope='all'` personal key** (reuse existing `control_api_keys.scope`, no migration).
2. **Per-request tenant selection** via `X-Trail-Tenant: <slug>`; resolveApiKey verifies the slug is a membership of the key user, routes to that tenant's engine+bearer; no header → home tenant fallback.
3. **`GET /api/control/my-tenants`** (key-authed, admin-local, not proxied) — membership tenants; non-'all' key sees only home tenant.
4. **Station tenant picker** (custom popover, no native select) + X-Trail-Tenant on every call + KB reload on switch.
5. **Logo + identity** — Trail concentric-circle mark + mono `trail` wordmark + `ingest` subtitle + tab favicon.
6. **Mint cb a scope='all' key**, write to `.env.local-ingest`, revoke old.

**Non-goals:** RBAC role enforcement, cross-org keys, engine routing changes, cookie/magic-link login in the Station.

## Security

A `scope='all'` key can only reach a tenant the owning user has a membership row for — the header is a selector, not a grant. Unknown/forged slug → 401. Legacy `scope='full'` keys untouched.

## Verification

Prod round-trip: scope=all key + X-Trail-Tenant broberg-ai → broberg-ai KBs; sanne-andersen → Sanne's KBs; bogus slug → 401. /my-tenants returns both for cb. Negative: scope='full' key ignores the header.

## Rollout

1. `pnpm ship:admin` (additive, no migration). 2. Mint scope='all' key, update .env, revoke old. 3. Station picks up picker+logo on next `trail ingest`.
