# F191.3 — `apps/ingest-station` shell + shared `packages/ingest-ui`

Parent: [F191](./F191-local-ingest-station.md).

## Scope
1. **Extract shared UI.** Pull the Sources view, drop-zone, and ingest-status/list components out of `apps/web` into `packages/ingest-ui` (single source — honours the "én kilde" rule; the two drop-zones must never drift). apps/web imports from the package; behaviour unchanged.
2. **Station app.** New `apps/ingest-station` (Vite 5.4 + Preact 10 + TS, per the lightweight stack). Thin shell: no nav to neurons/queue/graph/settings — ONLY Sources. Localhost dev port via the launcher (not a hardcoded default).
3. **Auth + tenant picker.** Authenticate against the cloud control-plane (app.trailmem.com). Open question (in epic): reuse magic-link session vs a pasted personal API key (F188 `trail_`); lean personal key for a thin tool. List the user's tenants; selecting one scopes all uploads.
4. **Intake.** Drop files → upload + extract via the cloud engine → park awaiting-local-compile (F191.1). File-type validation/control comes free with the shared components.

## Non-goals
No compile here (that's the cc skill, F191.2). No local DB. No other admin surface.

## Dependencies
F191.1 (lifecycle); control-plane auth (F186/F188); apps/web Sources components (to extract).
