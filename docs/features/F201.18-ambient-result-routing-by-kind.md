# F201.18 — Ambient search/chat results route by kind

## Motivation

After F201.17 landed (a logged-out Neuron deep-link now survives login), clicking
a search result in the Ambient HUD reached the admin at
`/kb/<kb>/neurons/<slug>` — but showed **"No Neuron matches slug
`ambient-speech-1783106841204` in this Trail."**

Root cause (confirmed via the search API): the hit is a **raw ambient Source**
(`kind: "source"` — a dictation, first-class Source since F201.13), NOT a
compiled Neuron. The Ambient app builds `NeuronHit` **without looking at
`kind`** and links EVERYTHING to the Neuron reader, which only renders
`kind='wiki'` docs → not-found. Christian's dictation exists; it's just a
Source, so it must open the **source view**, not the Neuron reader.

Second, cosmetic bug: the reader's not-found title renders the raw i18n key
`wikiReader.notFoundTitle` — that key is referenced in `wiki-reader.tsx` but
never defined in the locale files (the `wikiReader` block only has `userNote`).

## Scope

**In:**
- Ambient app (`apps/ambient-capture`): `NeuronHit` + `Citation` gain a `kind`
  field (parsed from the API, default `"wiki"`). A single
  `TrailClient.docURL(id:slug:kind:)` builds the URL — `source` →
  `/kb/<kb>/sources?expanded=<docId>` (the admin's existing source deep-link,
  used by upload-dropzone/images), else `/kb/<kb>/neurons/<slug>`. HUD `open()`
  routes by kind for both `hitRow` (search) and `citationRow` (chat).
- SPA i18n: add `wikiReader.notFoundTitle` to `da.json` + `en.json`.

**Out:** the F201.17 login-returnTo (done + live); refactoring the reader's
other hardcoded not-found strings (body + button are hardcoded English today —
pre-existing, not this bug); any engine/search change (the API already returns
`kind`).

## Files

- `apps/ambient-capture/Sources/TrailAmbient/TrailClient.swift` — `kind` on
  `NeuronHit`/`Citation`, parse it, `docURL(id:slug:kind:)` (replaces
  `neuronURL(slug:)`).
- `apps/ambient-capture/Sources/TrailAmbient/HudView.swift` — `open(id:slug:kind:)`;
  `hitRow`/`citationRow` pass the hit's id+slug+kind.
- `apps/admin/src/locales/{da,en}.json` — `wikiReader.notFoundTitle`.

## Verification

- Ambient: `swift build` clean; a SELFTEST assertion that `docURL` yields
  `/sources?expanded=` for kind=source and `/neurons/<slug>` for kind=wiki;
  rebuild + relaunch the app. Christian then clicks a dictation hit → lands on
  the source view (not 404).
- SPA: typecheck clean; the not-found title reads properly (needs a trail-admin
  redeploy to show live — cosmetic, bundled with the next deploy).
