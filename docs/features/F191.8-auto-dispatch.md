# F191.8 — Auto-dispatch (parked sources drain themselves, hands-off)

**Parent:** [F191 — Local Ingest Station](F191-local-ingest-station.md)

F191.1–.7 made local-ingest work but the TRIGGER was never wired — parking a source notifies nobody, so nothing happens until a human types /local-ingest. Christian's requirement: 100% automatic.

## Hard constraint
$0 compile REQUIRES an interactive cc session on Max (headless claude -p / cron = API-billed). So automation can't compile by itself — it must (a) detect pending sources via a LOCAL poll of the cloud ?awaitingLocalCompile=true endpoint (cloud can't reach the Mac), and (b) instruct a RUNNING interactive cc session to drain them.

## Scope (both, in sequence — Christian's call)
- **A. Interim — trail-session loop:** this interactive $0 session polls (~90-120s) over the key's tenants; drains pending (incl. F191.7 vision) or idles. Demonstrable now; only while the session is open.
- **B. Durable — buddy poller + dispatcher:** buddy (always-on, monitors sessions) polls cloud every ~60s; on pending, intercoms a drain to the RUNNING trail session (NOT a headless launch — stays $0). The upmetrics-remediation pattern F191.2 referenced. Implemented in the buddy repo via the buddy peer session.

## Non-goals
Headless/cron compile (breaks $0); a new launchd daemon (apps/agent doesn't exist; buddy is already the local orchestrator); changing Neuron approval policy.

## Verify
A: arm loop → drop real file → drains within one interval → Neurons appear, no command. B: close loop → buddy detects + intercoms trail → drains; confirm no headless claude -p spawned.

## Rollout
1. Arm trail-session loop now (A). 2. Coordinate buddy session for poller+dispatch (B); retire the interim loop once live.
