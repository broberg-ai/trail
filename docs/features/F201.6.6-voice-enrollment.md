# F201.6.6 — Voice enrollment (speaker-gate ambient capture)

> Task under F201.6 (Audio-tap + mic + on-device STT). Approved by Christian
> 2026-07-05 ("2 GO"), enrollment-first / LoRA-only-if-needed.

## Motivation
Ambient capture should record the OWNER's knowledge — not the TV, not other
people in the room, not a colleague on a call. A lightweight voice-print lets
the capture gate on "is this the owner speaking?" so background voices never
become Neurons. It also enables who-said-what (diarization) in meetings.

Context from the STT work (F201.15/F201.16): the built-in Mac mic transcribes
the owner fine at mono with no noise fix; voice-processing (option A) was
rejected (it exposed a 7-channel array that broke the recogniser). So this
task is about SPEAKER FILTERING, not noise-fixing.

## Scope
- Enroll a **voice-print** (speaker embedding — e.g. a compact on-device
  speaker-verification model, NOT a LoRA/Whisper fine-tune) for the owner from
  sample audio.
- Gate ambient capture on the print: non-owner speech (other people, TV) is
  not turned into a candidate; owner speech is.
- On-device + local storage only — no audio egress (Trail's capture guarantee).

## Corpus (already accumulating)
Extraction mode ALREADY keeps `WAV + transcript` per dictation, so the
voice+text dataset that both enrollment AND any future fine-tune would need is
being built passively — nothing wasted.

## Non-goals (v1)
- NO model fine-tuning. LoRA/Whisper fine-tune is a LATER phase, gated on
  evidence that batch-WhisperKit + speech-dictionary still isn't good enough
  for the owner's voice — decided with data, not upfront (heavy pipeline:
  train → re-quantize → CoreML, for marginal gain).
- No added latency to Prompt Mode.

## Dependencies
- F201.6 (audio-tap + mic + on-device STT) — the capture path this gates.

## Rollout
- App-only (apps/ambient-capture). No server/deploy.

## Acceptance criteria
- AC1: an on-device voice-print is enrolled for the owner from sample audio;
  no audio egress; print stored locally.
- AC2: ambient capture gates on the print — a non-owner/TV voice does NOT
  become a candidate, the owner's speech does (speaker-match test over an
  owner sample + a non-owner sample).
- AC3: LoRA/fine-tune is explicitly out of v1 scope (deferred, evidence-gated).
