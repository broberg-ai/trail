## Scope

- `GET /api/v1/documents?awaitingLocalCompile=true&kb=<id|slug>[,<id|slug>…]`
- Hver værdi slås op som id ELLER slug i tenanten (samme `resolveKbId` som resten
  af ruterne). Ukendt → 400 `{ error, unknown: [...] }`.
- Uden `kb` → uændret.

## Non-goals

- Ingen eksklusions-parameter. Se constraints.
- Ingen ændring af Foragers probe — deres egen beslutning.
- Ingen omdøbning af `documents`/`ids`.

## Arkitektur

Én ekstra `inArray(documents.knowledgeBaseId, ids)` i where-klausulen i
`apps/server/src/routes/documents.ts`. Test i `probe-kontrakt.test.ts` +
`apps/server/scripts/verify-probe-kontrakt.ts` kalder den levende rute i begge
retninger.
