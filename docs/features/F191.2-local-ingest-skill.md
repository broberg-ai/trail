# F191.2 — `/local-ingest` cc skill + buddy-instantiated pickup

Parent: [F191](./F191-local-ingest-station.md).

## Correction (Christian, 2026-06-04): write via REST, NOT MCP

The local-ingest session is already authed to the closed-network cloud peer (its `trail_` key), so it writes Neurons via the **plain cloud REST API**. No MCP. Earlier I proposed building an HTTP trail MCP — that was anchoring on the cloud-ingest MCP pattern. Verified the trail MCP (`apps/mcp`) is **stdio-only on a local DB** (no HTTP transport anywhere in the repo), so it could never reach the cloud KB; the idea is dropped (no F191.6).

## Write surface (the only new endpoint)
`POST /api/v1/knowledge-bases/:kbId/wiki-write` wraps the SAME `CandidateQueueAPI.write` the cloud ingest backend uses (create / str_replace / append) → identical Neuron shape, same auto-approval policy, connector `mcp:claude-code`. Read (`/documents/:id/content`) + search (`/knowledge-bases/:kb/search`) already exist as REST, so this was the only gap.

## The skill — the $0 in-session compile driver
`.claude/skills/local-ingest.md`. When invoked (manual or buddy-dispatched) for a KB:
1. List awaiting sources: `GET .../documents?awaitingLocalCompile=true`.
2. Per source: `GET .../compile-prompt` → follow the exact 9-step prompt, mapping its `read`/`search`/`write` tool-calls to the REST endpoints above; **YOU** (the interactive cc session) do the compile reasoning ($0 Max-plan — the REST calls are data I/O, not LLM calls).
3. `POST .../local-compiled` to clear the flag → engine stamps the F191.5 free-run.

**Invariant:** never `claude -p`, never an API key, never `/reingest` — all cost money.

## Pickup
- Manual: `/local-ingest <kb>`.
- buddy-dispatched (the upmetrics-remediation pattern): Station → buddy instantiates an ingest job in a cc session (`launch_agent` / intercom task) → it runs Step 2.

## Run recipe (no MCP setup)
`export TRAIL_CLOUD_API=https://app.trailmem.com TRAIL_API_KEY=trail_…` (key from cloud admin → Settings → API-nøgler) → `/local-ingest <kb-slug>`.

## Dependencies
F191.1 (awaiting state + query, shipped); the `trail_` key (F188); `wiki-write` (shipped). No MCP, no `.mcp.json` change.
