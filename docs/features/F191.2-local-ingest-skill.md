# F191.2 — `/local-ingest` cc skill

Parent: [F191](./F191-local-ingest-station.md).

## Scope
The $0 compile engine, expressed as a cc skill (`.claude/skills/local-ingest.md`). When invoked in an interactive session it:
1. Resolves the active tenant/KB (from MCP context or skill args).
2. Queries awaiting-local-compile sources (F191.1 endpoint) via trail MCP.
3. For each: fetches the extracted content + the Trail compile prompt, compiles IN-SESSION (claude itself = $0 Max-plan), and `write`s the Neuron(s) into the cloud KB via trail MCP.
4. Marks the source done; lets the engine's free-run telemetry (F191.5) fire on the write.

Mirrors the existing `/reingest` compile-only semantics, but the compute is the human's session instead of cloud OpenRouter. Reuses the compile prompt from apps/server/src/services/ingest.ts (exposed/fetchable rather than duplicated).

## Decoupling
The skill drains a cloud-side pending queue — "any cc session" with trail MCP + the skill can run it. No dependency on the Station being open; the Station just fills the queue.

## Optional
A SessionStart (or periodic) auto-drain hook so a session left open keeps draining, like this repo's `queue-drain`.

## Non-goals
No Station UI; no new LLM call (the session IS the LLM).

## Dependencies
F191.1 (awaiting-local-compile state + query); trail MCP write; the compile prompt template.
