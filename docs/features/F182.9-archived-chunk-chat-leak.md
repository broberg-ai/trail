# F182.9 — Archived Neurons must not leak into chat answers

> Sub-story of F182 (Memory Lifecycle). A defect in F182.6's domain
> (decay-aware reader/chat/queue surfacing): archived Neurons are supposed to
> be gone from chat, but their chunks still reach the answer.

## Motivation
Trail's admin "delete" on a Neuron is a soft-delete (archive): it sets
`archived = 1` and does NOT remove the row or its chunks. That is by design
(the F182 non-goal preserves history). But archived content is expected to be
GONE from the user's view — including chat.

It is not. The document-level FTS search filters `AND d.archived = 0`, but the
CHUNK-level FTS search (`CHUNKS_SQL` in `packages/db/src/search.ts`) does NOT.
Chat retrieval (`retrieveContext` in `apps/server/src/routes/chat.ts`) pulls
`searchChunks` and pushes every wiki chunk into the LLM context. So an archived
Neuron's prose still reaches chat answers — the model sees it and can echo it,
uncited.

This is a privacy/correctness leak affecting EVERY tenant, including
sanne-andersen (Eir). Discovered 2026-07-04 when a private dictation's Neuron
had to be HARD-deleted (not just archived) to actually remove it from retrieval.

## Scope
- Add `AND pd.archived = 0` to `CHUNKS_SQL` in `packages/db/src/search.ts`, so
  `searchChunks` never returns chunks belonging to an archived document —
  matching the filter `DOCUMENTS_SQL` already applies.
- A RED regression test in `packages/db` (bun test) that inserts a wiki Neuron
  + chunk, confirms `searchChunks` finds it, archives the Neuron, and asserts
  `searchChunks` no longer returns it. RED before the fix, GREEN after; wired
  into `turbo run test`.

## Non-goals
- No change to hard-delete, supersession, or the archive semantics.
- Raw SOURCE chunks are already excluded from chat (`hit.kind !== 'wiki'` skip
  in chat.ts) — this fix is about wiki/Neuron chunks only.
- No new UI.

## Rollout
- Deploy trail-engine-001 (`pnpm ship:engine`). Backend-only, no schema change,
  no migration — the fix is a WHERE-clause addition, live on next deploy.

## Acceptance criteria
- AC1: `searchChunks` returns a non-archived Neuron's chunk for a matching term,
  and does NOT return it once the Neuron is archived.
- AC2: The regression test lives in `packages/db` and runs under `turbo run
  test`; RED without the fix, GREEN with it.
- AC3: `CHUNKS_SQL` carries `AND pd.archived = 0`, deployed to trail-engine-001.
